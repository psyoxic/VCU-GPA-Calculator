VCU GPA Calculator



A desktop GPA calculator built with Python and CustomTkinter, featuring a black and gold interface inspired by Virginia Commonwealth University.

## Aplication Preview

VCU GPA Calculator <img width="800" alt="VCU GPA Calculator Preview" src="https://github.com/user-attachments/assets/2261b254-2eaf-40a4-818a-db3468ba4c3c" />


Features

* Calculate credit-weighted GPA
* Add and remove individual classes
* Display numerical and letter grades
* Calculate cumulative GPA using previous GPA and credits
* Automatically save and load class information
* Validate user inputs
* View GPA and total credits in a live dashboard



Technologies Used



* Python
* CustomTkinter
* Tkinter (ttk)
* JSON



Installation



1. Install Python.

2\. Install the required package:

&#x09;pip install -r requirements.txt

3\. Run the application:

&#x09;python gpa\_calculator.py
